# Third-party references and assets

## ScholaFlow
The uploaded ScholaFlow source archive is MIT-licensed (see the included ScholaFlow `LICENSE` notice recorded in the reference upload). CampusClass includes selected public landing/app illustrations under `reference-assets/scholaflow/` and adapts high-level classroom workflow ideas: stream posts, topic categorization, discussions, messaging, notes, to-do organization, and lesson/classwork flows. The original authentication engine, data schema, and database backend were not copied. CampusClass retains its Next.js + Supabase college tenancy and RLS policies.

## LMS Front
Reference: https://github.com/guillermoscript/lms-front. Its README declares MIT licensing. CampusClass uses the repository as a feature and UX reference and adapts concepts such as tenant theming, course/lesson content, exams, progress, AI tutor roadmap, gamification, and certificates to institution-owned college academics. No LMS Front app source tree is copied into this project.

Keep this notice and the source license files when redistributing derivative assets or code.
